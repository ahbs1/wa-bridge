API Reference

All endpoints require Authorization: Bearer {token} header.

📋 Sessions

POST /api/sessions Create session
GET /api/sessions List sessions
GET /api/sessions/:id Get session info
GET /api/sessions/:id/qr Get QR code
DEL /api/sessions/:id Delete session
POST /api/sessions/:id/restart Restart

💬 Messages

POST /api/:session/messages/send-text {chatId, text}
POST /api/:session/messages/send-image {chatId, url|base64, caption?}
POST /api/:session/messages/send-video {chatId, url|base64, caption?}
POST /api/:session/messages/send-document {chatId, url|base64, filename}
POST /api/:session/messages/send-voice {chatId, url|base64}
POST /api/:session/messages/send-location {chatId, lat, lng}
POST /api/:session/messages/send-contact {chatId, vcard}
POST /api/:session/messages/send-poll {chatId, title, options[]}
PUT /api/:session/messages/edit {chatId, messageId, text}
DEL /api/:session/messages/delete {chatId, messageId}
POST /api/:session/messages/react {chatId, messageId, emoji}

POST /webhook/chatwoot/:session Chatwoot webhook (per-session)
